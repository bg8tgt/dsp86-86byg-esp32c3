## 快速使用

1. **看接线**：打开 `ESP32C3_DSP86_86BYG450_接线与调试手册.docx`，或直接看 01～04 四张图。
2. **烧网页控制器**：进入 `web_controller/`，运行 `pio run -t upload`（已固定 COM6）；或双击 `flash_com6.ps1`。
3. **用网页**：连热点 `DSP86-C3`（密码 `dsp86c3ap`）→ 打开 `http://192.168.4.1`；默认 STA 为 `<wifi-ssid>` / `<wifi-password>`。
4. **烧 Arduino 示例**：用 Arduino IDE 打开 `esp32c3_dsp86/esp32c3_dsp86.ino`，开发板选 **ESP32-C3**，端口 **COM6**。
5. **装 Skill**：把 `skills/dsp86-86byg-esp32` 整个文件夹复制到 DSH 的 `.agents/skills/` 下，即可在后续会话中调用 `dsp86-86byg-esp32`。
6. **算拨码**：
   ```bash
   python skills/dsp86-86byg-esp32/scripts/dip_calc.py --current 4.86 --ppr 400 --motor 5.0 --connection 4wire --lead 5
   ```

## 关键参数速查

- **ESP32-C3**：STEP=GPIO4，DIR=GPIO5，ENA=GPIO6，LIMIT=GPIO1，PITCH=GPIO3（ADC1_CH3）
- **DSP86**：AC 18–80 V 输入（本系统 24 VAC），4.86 A，400 步/转
- **拨码**：SW1=off、SW2=on、SW3=off、SW4=off、SW5–SW8=on
- **电机**：黄 A+、蓝 A−（0.5 Ω）；红 B+、绿 B−（0.2 Ω）
- **注意**：0.2 Ω 那相建议表笔归零复测；方向反了交换黄/蓝
