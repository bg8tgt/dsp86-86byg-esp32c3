## 5. ESP32-C3 GPIO 规划

| 类别 | GPIO | 用途/限制 |
|---|---|---|
| 推荐 IO | 4、5、6、7、15、16、17、18、21、38–42、47、48 | 通用 |
| 启动绑带 | 0、3、45、46 | 上电电平敏感 |
| USB | 19、20 | D−/D+ |
| Flash/PSRAM | 26–37 | 模组内部 |
| UART0 | 43、44 | 日志串口 |

本方案：STEP=4，DIR=5，ENA=6，LIMIT=1（内部上拉），PITCH=3（ADC1_CH3，0–3.3 V）。

## 6. 公式

```
步距角   = 1.8° / (脉冲每转 / 200)
脉冲当量 = 导程 / 脉冲每转            [mm/step]
转速     = 脉冲频率 / 脉冲每转 × 60   [rpm]
```

400 步/转、5 mm 导程：0.9°、12.5 µm/step、400 Hz = 60 rpm。

## 7. 共阳接线

```
5V    → PUL+ / DIR+
GPIOx → PUL-
GPIOy → DIR-
GPIOz → ENA-（可选）
GPIOa → 限位/急停（到 GND）
GPIOb → 俯仰角 ADC（0–3.3 V）
GND   → 不接（光耦隔离）
```
